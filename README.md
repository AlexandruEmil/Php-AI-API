# Php-AI-API

Tehnologii recomandate pentru chatbot AI în PHP
✅ Backend: PHP (Laravel sau Slim pentru API)
✅ AI/NLP: OpenAI GPT, Rasa, sau un model NLP antrenat pe texte juridice
✅ Bază de date: MySQL/PostgreSQL pentru stocarea întrebărilor/răspunsurilor
✅ Frontend (opțional): React/Vue.js sau un simplu chatbot UI în HTML+JS
✅ Integrare API: OpenAI API sau Hugging Face pentru NLP

Funcționalități principale
1️⃣ Răspunsuri la întrebări juridice (bazate pe legislație)
2️⃣ Analiză și clasificare a problemelor juridice
3️⃣ Generare de modele de contracte (opțional)
4️⃣ Stocare și analiză a interacțiunilor
5️⃣ Autentificare și istoricul conversațiilor

1️⃣ Formular de chat pe site cu istoric afișat.
2️⃣ Stilizare de bază pentru o interfață simplă și funcțională.
3️⃣ Mesajele utilizatorului și răspunsurile AI sunt salvate și afișate cronologic.
